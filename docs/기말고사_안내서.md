**1. 개요**

기말고사는 중간고사에서 수립한 계획을 실제로 구현하고, 1~13주차에 배운
기술을 종합해 완성된 프로젝트로 증명하는 것으로 진행됩니다. 13주차 첫
번째 수업일까지 구현과 제출을 마치고, **<span class="mark">\[13주차
2번째 수업\]</span>**부터 15주차까지 발표합니다.

| **평가 비중** | 전체 성적의 40%                                                     |
|---------------|---------------------------------------------------------------------|
| **시행 시점** | 13주차(최종 제출) ~ 15주차(발표 종료)                               |
| **진행 방식** | 중간고사와 동일한 개인 구성                                         |
| **평가 목적** | 계획을 실제로 완성하고, 배운 기술을 종합적으로 증명하는 능력을 평가 |

**2. 평가 범위**

1~13주차 전체 내용을 종합적으로 활용합니다.

- 1~4주차: Copilot 자동완성·Chat·프롬프트 엔지니어링

- 5~10주차: Python·JavaScript·DOM·UI·API·SQL 언어별 실전 기술

- 11~13주차: 테스트 코드 작성, 디버깅과 코드 리뷰, 리팩토링

**'종합적으로 활용'의 의미**

- 5~10주차의 언어와 기술을 모두 포함할 필요는 없습니다. 프로젝트에 맞는
  기술을 골라 사용하면 되며, 포함하지 않은 기술 때문에 감점되지
  않습니다.

- 평가의 핵심은 Copilot 활용 → 구현 → 테스트 → 디버깅·코드 리뷰 →
  리팩토링으로 이어지는 과정을 프로젝트에 적용했는지입니다.

- 수업에서 다루지 않은 기술(예: Flask)도 사용할 수 있습니다. 단,
  README만으로 실행할 수 있어야 하고 발표 질의응답에서 해당 코드를 직접
  설명할 수 있어야 합니다.

**3. 요구사항 (제출물)**

1.  **전체 소스 코드** (저장소 링크 또는 zip 파일)

2.  **README** (아래 표의 필수 항목 포함)

3.  **테스트 케이스 5개 이상 및 통과 결과** — 최소 1개는 예외
    상황(잘못된 입력, 빈 데이터 등)을 다룰 것. 통과 결과는 실행 화면
    스크린샷 또는 실행 로그로 제출

4.  **리팩토링 전/후 비교 또는 리팩토링 근거 설명** (최소 1개 항목)

5.  **발표 자료** (문제 정의 → 해결 방법 → 데모 → 회고, 5~10분 분량).
    회고에는 중간고사 계획에서 바뀐 점과 그 이유를 포함

> →※ 2, 3, 4 항목은 기말보고서 PDF 파일로, 5 항목은 별도의 PPT 파일로
> 제출.

**6. 자주 묻는 질문**

**Q. 수업에서 배운 기술(JavaScript·DOM·SQL 등)을 모두 써야 하나요? A.**
아니요. 프로젝트에 맞는 기술을 골라 사용하면 됩니다. 과정(Copilot 활용 →
구현 → 테스트 → 디버깅·코드 리뷰 → 리팩토링)을 적용했는지가 더
중요합니다.

**Q. 수업에서 다루지 않은 기술(예: Flask)을 써도 되나요? A.** 네. 다만
README만으로 실행할 수 있어야 하고, 발표 질의응답에서 해당 코드를 직접
설명할 수 있어야 합니다. MVP와 테스트를 먼저 완성한 뒤 확장하는 순서를
권장합니다.

**Q. 중간고사 계획과 다르게 구현해도 되나요? A.** 네. 무엇이, 왜
바뀌었는지 README와 발표 회고에서 설명하면 오히려 가점 요인이 될 수
있습니다.

**Q. MVP를 다 완성하지 못하면 0점인가요? A.** 아닙니다. 부분 완성도에
따라 부분 점수가 부여됩니다. README의 MVP 체크리스트에 완성하지 못한
부분과 그 이유를 적어 주세요.

**Q. Copilot 없이 직접 짠 코드만 인정되나요? A.** 아니요. 이 과정은
Copilot을 능숙하게 활용하는 것 자체가 핵심 역량이므로, Copilot을 적극
활용한 코드가 권장됩니다. 다만 발표 질의응답에서 본인이 그 코드를 설명할
수 있어야 합니다.

**Q. 저장소 링크를 제출한 뒤에도 커밋해도 되나요? A.** 커밋은 할 수
있지만, 채점은 제출 기한 전 마지막 커밋 기준으로 합니다.

**기말고사 안내서**

캡스톤 프로젝트 구현 및 발표

***VSCode + GitHub Copilot 활용 실무 프로그래밍 입문 (초급 트랙)***

# **1. 개요**

기말고사는 중간고사에서 수립한 계획을 실제로 구현하고, 15주간 배운 기술을 종합해 완성된 프로젝트로 증명하는 것으로 진행됩니다. 13주차까지 구현을 완성하고, 14, 15주차에 발표를 마칩니다.

|               |                                                                     |
|---------------|---------------------------------------------------------------------|
| **평가 비중** | 전체 성적의 40%                                                     |
| **시행 시점** | 14주차 ~ 15주차(완성 및 발표)                                       |
| **진행 방식** | 중간고사와 동일한 개인 구성                                         |
| **평가 목적** | 계획을 실제로 완성하고, 배운 기술을 종합적으로 증명하는 능력을 평가 |

# **2. 평가 범위**

1~13주차 전체 내용을 종합적으로 활용합니다.

- 1~4주차: Copilot 자동완성·Chat·프롬프트 엔지니어링

- 5~10주차: Python·JavaScript·DOM·UI·API·SQL 언어별 실전 기술

- 11~13주차: 테스트 코드 작성, 디버깅과 코드 리뷰, 리팩토링

# **3. 요구사항 (제출물)**

> **1.** 전체 소스 코드 (저장소 링크 또는 zip 파일)
>
> **2.** README (프로젝트 소개, 설치법, 사용법, 실행 화면 스크린샷 권장)
>
> **3.** 최소 5개 이상의 테스트 케이스 및 통과 결과
>
> **4.** 리팩토링 전/후 비교 또는 리팩토링 근거 설명 (최소 1개 항목)
>
> **5.** 발표 자료 (문제 정의 → 해결 방법 → 데모 → 회고, 5~10분 분량)

# **6. 자주 묻는 질문**

**Q. 중간고사 계획과 다르게 구현해도 되나요? A.** 네. 다만 무엇이, 왜 바뀌었는지 발표에서 간단히 설명하면 오히려 가점 요인이 될 수 있습니다.

**Q. MVP를 다 완성하지 못하면 0점인가요? A.** 아닙니다. 부분 완성도에 따라 부분 점수가 부여됩니다. 완성하지 못한 부분과 그 이유를 README에 명시해 주세요.

**Q. Copilot 없이 직접 짠 코드만 인정되나요? A.** 아니요. 이 과정은 Copilot을 능숙하게 활용하는 것 자체가 핵심 역량이므로, Copilot을 적극 활용한 코드가 권장됩니다. 다만 발표 질의응답에서 본인이 그 코드를 설명할 수 있어야 합니다.

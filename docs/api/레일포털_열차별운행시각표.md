# 레일포털 Open API: 열차별 운행시각표

2호선·7호선 시간표를 받는 데 쓰는 API입니다. **실행 중인 앱에서는 부르지 않고**, 개발할 때 `tools/fetch_kric.py`로 한 번만 받아 `data/trips.js`에 합칩니다.

- 제공: 철도산업정보센터 레일포털 (https://data.kric.go.kr)
- 서비스 ID / 오퍼레이션 ID: `trainUseInfo` / `subwayTimetable`
- 사용 기간: 2026.11.09 ~ 2027.11.09
- **인증키는 이 문서와 저장소에 적지 않습니다.** 키는 사용자가 따로 보관하고, 스크립트를 실행할 때 입력합니다.
- 범위: 도시철도·광역철도만 (일반역·KTX역 제외). 운영기관이 원천 데이터를 주지 않으면 빠질 수 있음

## 담당자 요청 사항 (발급 메일)
> 서비스별 요청 횟수 제한은 없지만 매크로 실행은 자제해 주십시오. 1일 1회 GET 또는 배치 작업으로 해 주시기를 요청합니다. 과도한 GET이 일어날 경우 불이익을 당할 수 있습니다.

그래서 이 프로젝트는 **시간표를 미리 받아 파일로 넣고, 앱 실행 중에는 API를 부르지 않습니다.** 다운로드 스크립트도 1초에 한 번씩만 호출합니다.

## 요청

```
GET https://openapi.kric.go.kr/openapi/trainUseInfo/subwayTimetable
```

| 파라미터 | 설명 | 예 |
|---|---|---|
| `serviceKey` | 인증키. `$`, `/`가 들어 있어 **URL 인코딩 필수** (`$`→`%24`, `/`→`%2F`) | |
| `format` | `json` 또는 `xml` | `json` |
| `railOprIsttCd` | 철도운영기관 코드 | `S1` (서울교통공사) |
| `lnCd` | 노선 코드 | `2` |
| `stinCd` | 역 코드 | `150` |
| `dayCd` | 요일 코드: `7` 토요일, `8` 평일, `9` 휴일 | `8` |

코드 값은 `레일포털_역사코드정보_2026.07.11.xlsx`의 "역사고유번호" 시트(RAIL_OPR_ISTT_CD, LN_CD, LN_NM, STIN_CD, STIN_NM)에 있습니다.

| 노선 | railOprIsttCd | lnCd | 역 수 |
|---|---|---|---|
| 2호선 | S1 (서울교통공사) | 2 | 51 |
| 7호선 | S1 (서울교통공사) | 7 | 42 |
| 7호선 인천 구간 | IC (인천교통공사) | 7 | 11 |

## 응답 (서울역 1호선 평일 예시, 일부)

```json
{
  "header": { "resultCnt": 488, "resultCode": "00", "resultMsg": "정상 처리되었습니다." },
  "body": [
    { "railOprIsttCd": "S1", "trnNo": "K10", "dayCd": "8", "dayNm": "평일", "stinCd": "150", "lnCd": "1", "arvTm": "064730", "dptTm": "064800" },
    { "railOprIsttCd": "S1", "trnNo": "K100", "dayCd": "8", "dayNm": "평일", "stinCd": "150", "lnCd": "1", "arvTm": "143830", "dptTm": "143900" }
  ]
}
```

- 한 역에 서는 **모든 열차**가 한 번에 옵니다 (페이지 나눔 없음).
- `arvTm`·`dptTm`은 `HHMMSS` 문자열입니다.
- **방향과 행선지가 없습니다.** 그래서 같은 노선·요일의 여러 역 응답을 `trnNo`(열차번호)로 묶고, 시각순으로 정렬하면 그 열차가 지나는 역 순서가 됩니다.

## trips.js로 합치는 방법

다운로드가 끝나면 프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
node tools/merge_kric.js
```

스크립트는 `tools/kric_out/kric_timetable.json.gz`를 읽고 `data/trips.js`를 갱신합니다. 이미 합쳐진 2·7호선 데이터는 먼저 제거하므로 같은 명령을 다시 실행해도 중복되지 않습니다.

1. `tools/kric_out/kric_timetable.json.gz`를 읽습니다. 모양: `{ "8|S1|2|0234": { line, name, rows: [[trnNo, arvTm, dptTm], ...] }, ... }`
2. 요일(8 평일 → `weekday`, 9 휴일 → `holiday`), 운영기관, 노선이 같은 것끼리 `trnNo`로 묶습니다. (7호선은 S1과 IC 구간이 같은 열차번호로 이어지는지 확인)
3. 역마다 `dptTm`(없으면 `arvTm`)을 자정 기준 분으로 바꾸고, 시각순으로 정렬해 `stops: [[역 이름, 분], ...]`을 만듭니다. 자정을 넘기면 1440을 더합니다.
4. 역 이름을 기존 trips.js와 맞춥니다 (예: 서울역, 홍대입구, 신도림, 온수, 가산디지털단지). 이름이 같아야 환승이 연결됩니다.
5. `{ no, line: "2호선" | "7호선", stops }`로 `TRIPS.weekday`, `TRIPS.holiday`에 추가합니다. 토요일은 휴일 시간표를 씁니다.
6. 주의: 2호선은 순환선이라 한 열차번호가 한 바퀴 이상 이어질 수 있습니다. 시각 간격이 크게 벌어지면 다른 운행으로 나눕니다.

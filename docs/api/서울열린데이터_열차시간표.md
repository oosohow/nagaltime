# 서울 열린데이터광장: 서울교통공사 역코드로 지하철 열차 시간표 검색

**2호선 토요일·휴일 시간표를 받는 데 씁니다.** 레일포털에는 2호선 평일 시간표만 있고 토요일(dayCd 7)·휴일(dayCd 9) 응답이 비어 있었습니다. 다운로드는 `tools/fetch_seoul.py`로 한 번만 하고, 결과(`tools/kric_out/seoul_line2.json.gz`)를 `node tools/merge_kric.js`로 `TRIPS.holiday`에 합칩니다. 이때 내선·외선만 사용하고 상행·하행은 제외합니다.

- 데이터셋: OA-101 / OA-22750 (서울교통공사 지하철역 열차시간표)
- 인증키: 열린데이터광장 **일반 인증키** (실시간 지하철 인증키로는 안 됨). 키는 저장소에 적지 않습니다.
- 범위: **서울교통공사 노선만.** 경의중앙선(가좌, `K315`)처럼 코레일이 운영하는 구간은 "해당하는 데이터가 없습니다(INFO-200)"가 나옵니다.

## 요청 (주소 순서 주의)

```
http://openapi.seoul.go.kr:8088/[일반인증키]/json/SearchSTNTimeTableByIDService/1/500/[요일]/[방향]/[역코드]/
```

| 자리 | 값 |
|---|---|
| 요일 | `1` 평일, `2` 토요일, `3` 휴일·일요일 |
| 방향 | `1` 상행·내선, `2` 하행·외선 |
| 역코드 | 예: 서울역 1호선 `0150`, 홍대입구 2호선 `0239` |

- 열린데이터광장 마이페이지의 "Open API 테스트"에서 API명을 고르면 요청 주소 예시가 나옵니다.

## 오류 메시지
| 코드 | 뜻 |
|---|---|
| INFO-100 | 인증키가 유효하지 않음 (실시간 전용 키를 넣었거나 오타) |
| INFO-200 | 데이터 없음 (역코드·방향이 틀렸거나 코레일 구간) |
| ERROR-300 | 필수 값 누락 (주소 순서 확인) |
| ERROR-336 | 한 번에 1000건 초과 요청 |

# 서울 열린데이터광장: 지하철 열차 시간표 (getTrainSch)

**2호선 토요일·휴일 시간표를 받는 데 씁니다.** 레일포털 API는 2호선 평일만 주고 토요일·휴일 응답이 비어 있어서 이 API로 채웠습니다. 앱 실행 중에는 부르지 않고, `tools/fetch_seoul.py`로 한 번만 받아 `tools/merge_kric.js`로 `data/trips.js`에 합칩니다.

- 제공: 서울 열린데이터광장 (https://data.seoul.go.kr)
- 인증키: 열린데이터광장 **일반 인증키** (실시간 지하철 인증키로는 안 됨). 키는 저장소에 적지 않고 실행할 때 `SEOUL_KEY` 환경 변수로 넣습니다.
- 받은 데이터의 유효 시작일: 2025-05-01 (`vldBgngDt`)

## 요청 (주소 순서 주의)

```
http://openapi.seoul.go.kr:8088/{인증키}/json/getTrainSch/{시작}/{끝}/{열차번호}/{임시시간표}/{상하행}/{요일}/{노선}/
```

| 자리 | 값 | 이 프로젝트에서 쓴 값 |
|---|---|---|
| 시작·끝 | 몇 번째 줄부터 몇 번째 줄까지 (한 번에 1000줄 이하) | 1~1000, 1001~2000 … |
| 열차번호 | 비우면 전체 | 빈칸(공백 한 칸) |
| 임시시간표 | `N` 정규 시간표 | `N` |
| 상하행 | 2호선은 `내선`·`외선` (`상행`·`하행`은 인천 2호선 데이터가 나옴) | `내선`, `외선` |
| 요일 | `평일`, `주말` 등 | `주말` |
| 노선 | 노선 이름 | `2호선` |

- 응답 한 줄 = 열차 하나가 한 역에 서는 시각입니다. 주요 필드: `trainno`(열차번호), `stnNm`(역 이름), `trainDptreTm`(출발 시각 HH:MM:SS), `vldBgngDt`(유효 시작일).
- `tools/fetch_seoul.py --check`로 어떤 상하행·요일 조합에 데이터가 있는지 먼저 확인할 수 있습니다.
- 평일 데이터는 레일포털과 대조해 같은 것을 확인했습니다(예: 2002번 열차 을지로입구 05:30).

## 오류 메시지
| 코드 | 뜻 |
|---|---|
| INFO-100 | 인증키가 유효하지 않음 (실시간 전용 키를 넣었거나 오타) |
| INFO-200 | 데이터 없음 (상하행·요일 조합이 틀림) |
| ERROR-336 | 한 번에 1000건 초과 요청 |

## 참고: 쓰지 않은 API
- `SearchSTNTimeTableByIDService`(역코드로 시간표 검색): 2026-11 확인 당시 모든 요청에 INFO-200(데이터 없음)이 나와 쓰지 않았습니다.
- 실시간 도착정보 API: "지금 몇 분 뒤 열차가 오나"만 알려 줘서 내일 아침 기상 시간 계산에는 쓸 수 없습니다.
